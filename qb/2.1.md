## Section C: 10-Mark Questions

**Q11.** [BT4 | CO1, CO2] *(Experiment E5 — Swap Nodes in Pairs, LeetCode #24)*

The "Swap Nodes in Pairs" problem requires swapping every two adjacent nodes in a linked list by relinking pointers — not by modifying node values.

**(a)** Design an iterative algorithm using a dummy header node. Describe the three pointer variables needed (`prev`, `curr`, `next_pair`) and explain the exact sequence of pointer reassignments required to swap one pair of nodes.

**(b)** Trace your algorithm on list HEAD → 1 → 2 → 3 → 4 → NULL. At each swap step, show the values of `prev`, `curr`, and `next_pair`, the pointer assignments performed, and the resulting list state. Show the state after all pairs are swapped.

**(c)** Analyse the time complexity (O(n)) and space complexity (O(1)) of the iterative approach. Compare with a recursive approach: write the recursive function and explain the trade-off in terms of call-stack depth and stack memory usage for a list of n nodes.

**Q12.** [BT4 | CO1, CO2]

A music player implements a playlist as a **circular doubly linked list**, where each node stores a song title and duration. The player supports four operations: `play_next()`, `play_prev()`, `add_song(title, duration)`, and `remove_song(title)`.

**(a)** Design the node structure and the `CircularDoublyLinkedList` class. Implement `play_next()` and `play_prev()` using a `current` pointer. Explain what happens when `current` reaches the tail during `play_next()`.

**(b)** Implement `add_song(title, duration)` to insert at the rear and `remove_song(title)` to delete a node by title. For each operation, draw the state of the list (showing `prev` and `next` pointers) before and after the operation.

**(c)** Derive the time complexity of all four operations. Justify why a circular doubly linked list is preferable to a singly linked list for this application — specifically addressing: backward navigation, deletion without traversing from head, and looping at list boundaries.

**Q13.** [BT4 | CO2]

A sparse polynomial P(x) = 5x⁴ + 3x² + 7 is to be represented as a linked list storing only non-zero terms.

**(a)** Design the node structure with fields for coefficient, exponent, and next pointer. Represent P(x) and Q(x) = x³ + 4x² + 5 as linked lists. Draw each list showing all nodes in decreasing order of exponent.

**(b)** Implement polynomial addition for two such linked lists. Trace the addition of P(x) and Q(x) step by step: show which nodes are compared, whether exponents match or differ, and the state of the result list after each step.

**(c)** Compare linked list representation against array representation (index = exponent, value = coefficient) for polynomial storage. For a polynomial of degree 1000 with only 4 non-zero terms, compute the memory used by each representation (int = 4 bytes) and conclude which is more space-efficient. State the time complexity of polynomial addition under each representation.
