**(a)** Design a hash-map solution using the sorted version of each string as its key. Write the complete Python implementation. State the time complexity in terms of n (number of strings) and k (maximum string length).

**(b)** Trace the algorithm on input = ["eat", "tea", "tan", "ate", "nat", "bat"]. For each string, show the key computed (sorted string), the hash map state after insertion, and the final grouped output.

**Q12.** [BT5 | CO2, CO3] *(Experiment E14 — Valid Anagram, LeetCode #242)*

The Valid Anagram problem determines whether string t is an anagram of string s.

**(a)** Implement three approaches:
  (i) Sort both strings and compare — O(n log n) time.
  (ii) Character frequency hash map (Python dict) — O(n) time.
  (iii) Fixed-size count array of 26 integers for lowercase English letters — O(n) time.
Write Python implementations for all three.

**(b)** Compare the three approaches across: time complexity, space complexity, and whether they support Unicode characters beyond ASCII. Recommend the best approach for: (i) strictly lowercase ASCII input, (ii) arbitrary Unicode input.

**(c)** Explain how the choice of collision resolution strategy in the underlying hash map affects the worst-case performance of approach (ii).
