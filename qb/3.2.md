**(b)** Trace the algorithm on intervals = [[1,2], [2,3], [3,4], [1,3]]. Show the sorted order, the current retained interval after each comparison, and the count of intervals removed. Identify which intervals are excluded.

**(c)** State the time complexity (O(n log n) for sorting, O(n) for the greedy scan). Explain how this greedy approach relates to the classical Activity Selection Problem. Discuss why a dynamic programming solution, while correct, is less efficient for this particular problem.
