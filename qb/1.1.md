## Section C: 10-Mark Questions

**Q11.** [BT4 | CO1]

A software engineer is analysing two candidate algorithms, P and Q, for processing a dataset of size n:
- Algorithm P performs T_P(n) = 4n² + 6n + 2 operations.
- Algorithm Q performs T_Q(n) = 80n log₂ n + 100 operations.

**(a)** Express T_P(n) and T_Q(n) in Big-Θ notation. Justify each using the formal definition with explicit constants c₁, c₂, and n₀.

**(b)** Determine the approximate crossover value n₀ beyond which Q outperforms P. Set up the inequality T_Q(n) < T_P(n) and solve numerically.

**(c)** For a dataset of size n = 10,000, calculate the approximate operation count of each algorithm. Select the better algorithm for this dataset and explain the importance of worst-case analysis in practical algorithm selection.

**Q12.** [BT4 | CO1, CO2]

A 2D integer array A[4][5] is stored with base address BA = 5000 and integer size = 4 bytes.

**(a)** Derive the address formula for element A[i][j] in row-major order. Using this formula, calculate the addresses of A[2][3] and A[3][4]. Show all steps.

**(b)** Re-derive the address formula for column-major order. Calculate the address of A[2][3] under column-major storage. Explain which programming languages use each ordering.

**(c)** If the same data were instead stored as a 3D integer array B[2][2][5] with BA = 5000, write the general row-major address formula for B[i][j][k] and compute the address of B[1][1][3].
