## Section C: 10-Mark Questions

**Q11.** [BT4 | CO1, CO5] *(Experiment E4 — Kth Largest Element, LeetCode #215)*

The problem requires finding the k-th largest element in an unsorted array without fully sorting it.

**(a)** Describe the QuickSelect algorithm — a variant of quick sort's partition step — that finds the k-th largest (or smallest) element in O(n) average time. Write the partition logic and the selection recursion clearly distinguishing the base case from the recursive cases.

**(b)** Trace QuickSelect on array [3, 2, 1, 5, 6, 4] to find the 2nd largest element (k = 2). At each step, show the pivot chosen (last element, Lomuto scheme), the array after partitioning, and the sub-array selected for the next recursive call.

**(c)** Compare three approaches to this problem: (i) QuickSelect — O(n) average, O(n²) worst; (ii) full sort then index — O(n log n); (iii) min-heap of size k — O(n log k). Recommend the best approach for each of: k = 1, k = n/2, and repeated queries on the same array. Justify using complexity analysis.

For an in-memory sort of 10⁶ integers with limited extra memory, recommend one algorithm and justify.
